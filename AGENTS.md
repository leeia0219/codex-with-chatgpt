# Repository instructions

Before configuring, repairing, or using Codex with ChatGPT:

1. Read `LOCAL_SETUP.md` when it exists. It contains this computer's trusted
   workspace path, fixed public hostname, ChatGPT App name, and Project name.
2. If it does not exist, copy `LOCAL_SETUP.example.md` to `LOCAL_SETUP.md` and
   fill in the values for this computer before running workspace commands.
3. Keep `LOCAL_SETUP.md` local. Never commit its real paths, hostname, tunnel
   identifiers, tokens, pairing codes, or credentials.
4. Read and follow `skill/SKILL.md` for the actual C2C workflow. The local file
   supplies machine-specific values; it does not replace the Skill.
5. Reuse the recorded fixed hostname and existing App/Project. Do not create a
   quick tunnel, duplicate connector, or duplicate Project unless the user asks.
